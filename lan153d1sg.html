📊 Domain 1 Overview

Domain Weight: 12% of exam

This domain covers the foundational concepts and principles of cybersecurity that form the basis for all other Security+ topics.

🎯 Learning Objectives

  • 1.1: Compare and contrast various types of security controls
  • 1.2: Summarize fundamental security concepts
  • 1.3: Explain the importance of change management processes

📈 Study Tips

  • Focus on understanding relationships between different security control types

  • Learn Zero Trust architecture components thoroughly
  • Understand change management security implications
  • Study PKI components and certificate management
🔒 1.1 - Security Controls ▼

📂 Security Control Categories

Technical Controls: Implemented using systems (firewalls, encryption, access controls)

Managerial Controls: Administrative policies and procedures

Operational Controls: Implemented by people (security guards, training)

Physical Controls: Protect physical assets (locks, cameras, barriers)

🎯 Security Control Types

Preventive: Stop incidents before they occur

Deterrent: Discourage potential attackers

Detective: Identify when incidents occur

Corrective: Respond to and remediate incidents

Compensating: Alternative protection when primary controls fail

Directive: Guide behavior through policies

🔐 1.2 - Fundamental Security Concepts ▼

🔺 CIA Triad

Confidentiality: Preventing unauthorized disclosure (encryption, access controls)

Integrity: Ensuring data accuracy and detecting changes (hashing, digital signatures)

Availability: Ensuring systems are accessible when needed (redundancy, fault tolerance)

🔑 AAA Framework

Authentication: Verifying identity (passwords, biometrics, certificates)

Authorization: Determining access permissions (RBAC, DAC, MAC)

Accounting: Tracking user activities (audit logs, monitoring)

🛡️ Zero Trust Architecture

Control Plane: Policy management, adaptive identity, threat reduction

Data Plane: Policy enforcement points, implicit trust zones

🏢 Physical Security

Perimeter: Bollards, fencing, lighting, access vestibules

Monitoring: Video surveillance, sensors (infrared, pressure, microwave)

Deception: Honeypots, honeynets, honeyfiles, honeytokens

🔄 1.3 - Change Management ▼

📋 Business Processes

Approval Process: Formal authorization and change control board review

Impact Analysis: Risk assessment and dependency evaluation

Backout Plan: Rollback procedures and recovery processes

Testing: Validation in controlled environments

⚙️ Technical Implications

Allow/Deny Lists: Application execution control

Downtime: Service, application, and system interruptions

Legacy Applications: Unsupported system challenges

Dependencies: Interconnected system considerations

🔐 1.4 - Cryptographic Solutions ▼

🗝️ PKI Components

Public/Private Keys: Asymmetric cryptography foundation

Certificate Authorities: Trusted third-party verification

Certificates: Digital identity credentials

Revocation: CRLs and OCSP status checking

🔒 Encryption Types

Symmetric: Single shared key (AES, fast processing)

Asymmetric: Public/private key pairs (RSA, key exchange)

Levels: Full-disk, file, database, transport encryption

🔧 Cryptographic Tools

HSM: Hardware security modules for key management

TPM: Trusted platform modules for secure boot

Hashing: Data integrity verification (SHA-256)

Digital Signatures: Authentication and non-repudiation
