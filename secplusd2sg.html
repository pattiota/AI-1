2.1 Compare and contrast common threat actors and motivations
0/10 ▼
2.1.1 Threat Actors
Nation-State
Government-sponsored actors with extensive resources, sophisticated capabilities, and long-term strategic objectives. Examples include APT campaigns targeting critical infrastructure.
Unskilled Attacker
Individuals with limited technical expertise using existing tools ("script kiddies"). Often opportunistic and thrill-seeking.
Hacktivist
Groups using hacking for political/social causes. Examples: Anonymous, environmental activists targeting corporations.
Insider Threat
Trusted individuals within organizations (malicious, negligent, or compromised insiders) with legitimate access and internal knowledge.
Organized Crime
Professional criminal organizations conducting profit-driven cyber operations including ransomware and financial fraud.
Shadow IT
Unauthorized IT systems, devices, or services that bypass official policies and create security risks.
2.1.2 Attributes of Actors
Internal/External
Internal threats have legitimate access but insider knowledge; External threats must gain unauthorized access.
Resources/Funding
High-resource (nation-states), medium-resource (hacktivists), low-resource (unskilled attackers).
Level of Sophistication
Advanced (custom malware, zero-days), Intermediate (modified tools), Basic (readily available tools).
2.1.3 Motivations
Data Exfiltration
Stealing sensitive information including intellectual property, customer data, and financial records.
Espionage
Gathering intelligence for competitive, political, or military advantage (industrial and state espionage).
Service Disruption
Preventing normal operations through DDoS attacks, system sabotage, or infrastructure attacks.
Financial Gain
Direct monetary profit through banking fraud, cryptocurrency theft, and ransomware operations.
Philosophical/Political Beliefs
Advancing ideological causes through website defacements, data leaks, and propaganda campaigns.
War
Military or strategic advantages in conflicts, targeting critical infrastructure and military systems.
2.2 Explain common threat vectors and attack surfaces
0/12 ▼
2.2.1 Message-Based Threats
Email
Phishing attacks, malware delivery, Business Email Compromise (BEC), spam, and email spoofing.
SMS
SMS phishing (smishing), malware links, social engineering, and SIM swapping attacks.
Instant Messaging
Malware spreading, social engineering, information gathering, and credential harvesting.
2.2.2 Image-Based Threats
Steganography
Hiding malicious code in image files and exploiting image processing vulnerabilities.
2.2.3 File-Based Threats
Malicious Documents
Office files with embedded macros, executable files, archive files, and script files.
2.2.4 Voice Call Threats
Vishing
Voice phishing, caller ID spoofing, voice synthesis, and information gathering through conversation.
2.2.5 Removable Device Threats
USB Attacks
USB-based malware, hardware implants, data exfiltration, and air-gap bridging.
2.2.6 Vulnerable Software
Client-Based vs. Agentless
Software vulnerabilities in installed applications vs. web-based services and third-party software.
2.2.7 Unsupported Systems
End-of-Life & Legacy
Systems no longer receiving security updates, accumulating vulnerabilities over time.
2.2.8 Unsecure Networks
Wireless Networks
Open networks, weak encryption, evil twin attacks, man-in-the-middle attacks.
Wired Networks
Physical access, network sniffing, VLAN hopping, switch vulnerabilities.
Bluetooth
Bluejacking, bluesnarfing, proximity attacks, device discovery.
2.2.9 Open Service Ports
Unnecessary Services
Running unneeded services with default configurations, vulnerable to port scanning and service exploitation.
2.2.10 Default Credentials
Factory Defaults
Unchanged manufacturer passwords, common passwords, administrative accounts with default settings.
2.2.11 Supply Chain Attacks
Managed Service Providers
Third-party access, privileged rights, trust relationships, cascade effects.
Vendors & Suppliers
Software vendors, hardware vendors, component suppliers, compromised update mechanisms.
2.2.12 Human Vectors/Social Engineering
Phishing, Vishing, Smishing
Email, voice, and SMS-based social engineering attacks targeting credentials and information.
Advanced Techniques
Misinformation/disinformation, impersonation, BEC, pretexting, watering hole, brand impersonation, typosquatting.
2.3 Explain various types of vulnerabilities
0/11 ▼
2.3.1 Application Vulnerabilities
Memory Injection
Exploiting memory management flaws for code injection, DLL injection, and process hollowing.
Buffer Overflow
Writing data beyond allocated memory boundaries, including stack and heap overflows.
Race Conditions
Timing-dependent vulnerabilities including Time-of-Check/Time-of-Use (TOCTOU) attacks.
Malicious Update
Compromised software updates containing malicious code via compromised servers or MITM attacks.
2.3.2 Operating System Vulnerabilities
OS-Based Flaws
Kernel vulnerabilities, privilege escalation, system service vulnerabilities, and configuration weaknesses.
2.3.3 Web-Based Vulnerabilities
SQL Injection (SQLi)
Injecting malicious SQL commands including in-band, blind, and time-based injection attacks.
Cross-Site Scripting (XSS)
Injecting malicious scripts including stored, reflected, and DOM-based XSS attacks.
2.3.4 Hardware Vulnerabilities
Firmware
Low-level software vulnerabilities including backdoors, weak authentication, and update mechanism flaws.
End-of-Life & Legacy
Hardware no longer supported by manufacturers, accumulating vulnerabilities without security updates.
2.3.5 Virtualization Vulnerabilities
VM Escape
Breaking out of VM isolation through hypervisor vulnerabilities and shared resource exploitation.
Resource Reuse
Data remnants from previous VM instances leading to information disclosure and data leakage.
2.3.6 Cloud-Specific Vulnerabilities
Cloud Security Issues
Shared responsibility model confusion, misconfigured storage, weak access controls, API vulnerabilities.
2.3.7 Supply Chain Vulnerabilities
Service, Hardware, Software Providers
Third-party dependencies, vendor security practices, compromised components, and malicious updates.
2.3.8 Cryptographic Vulnerabilities
Crypto Weaknesses
Weak algorithms, poor key management, implementation flaws, side-channel attacks, quantum threats.
2.3.9 Misconfiguration
Configuration Issues
Default settings, excessive permissions, unnecessary services, weak security settings, documentation gaps.
2.3.10 Mobile Device Vulnerabilities
Side Loading
Installing applications from unofficial sources, bypassing security controls.
Jailbreaking
Removing manufacturer security restrictions, disabling security features.
2.3.11 Zero-Day Vulnerabilities
Unknown Vulnerabilities
Previously unknown vulnerabilities with no available patches, often used in APT campaigns.
2.4 Analyze indicators of malicious activity
0/7 ▼
2.4.1 Malware Attacks
Ransomware
Malware that encrypts data and demands payment, including crypto-ransomware and double extortion variants.
Trojan
Malware disguised as legitimate software, including RATs, banking trojans, and downloaders.
Worm
Self-replicating malware that spreads across networks, causing congestion and performance issues.
Spyware
Malware that secretly monitors and collects information including keyloggers and screen recorders.
Virus, Rootkit, Logic Bomb
File-infecting malware, stealth malware that hides presence, and trigger-based malicious code.
2.4.2 Physical Attacks
Brute Force
Repeated attempts to guess passwords or access codes for physical locks and access systems.
RFID Cloning
Copying RFID card data to unauthorized devices for physical access bypass.
Environmental
Attacks targeting physical infrastructure including power disruption and cooling system attacks.
2.4.3 Network Attacks
DDoS
Distributed denial-of-service attacks including amplified and reflected attacks.
DNS Attacks
DNS poisoning, tunneling, and hijacking for traffic redirection and data exfiltration.
Wireless & On-Path
Evil twin attacks, wireless jamming, man-in-the-middle attacks, credential replay.
2.4.4 Application Attacks
Injection Attacks
SQL injection, command injection, LDAP injection leading to data breaches and system compromise.
Buffer Overflow & Privilege Escalation
Memory exploitation and gaining higher-level access than authorized.
Replay, Forgery, Directory Traversal
Retransmitting captured communications, CSRF attacks, and accessing files outside intended directories.
2.4.5 Cryptographic Attacks
Downgrade
Forcing use of weaker cryptographic algorithms for easier decryption.
Collision & Birthday
Finding different inputs with same hash output and exploiting collision probability mathematics.
2.4.6 Password Attacks
Spraying
Trying common passwords against many accounts to avoid lockout policies.
Brute Force
Systematically trying all possible password combinations, dictionary attacks, rainbow tables.
2.4.7 Indicators
Account & Access Indicators
Account lockouts, concurrent sessions, impossible travel, blocked content.
Resource & Logging Indicators
Resource consumption, inaccessibility, out-of-cycle logging, missing logs, published vulnerabilities.
2.5 Explain mitigation techniques for enterprise security
0/5 ▼
2.5.1 Segmentation
Network Isolation
Isolating network areas using VLANs, subnets, firewalls, and air gaps to contain threats and limit access.
2.5.2 Access Control
ACLs & Permissions
Access Control Lists defining specific permissions for resources, using DAC, MAC, and RBAC models.
2.5.3 Application Allow List
Application Whitelisting
Permitting only approved applications to run, preventing malware and enforcing compliance.
2.5.4 Isolation
System Isolation
Separating systems using physical isolation, VMs, containers, and sandboxes for security and testing.
2.5.5 Patching
Patch Management
Fixing known vulnerabilities through testing, staging, deployment, and verification processes.
