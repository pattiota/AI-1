Course Description

This course introduces the basic principles of network security. The student will be introduced to computer network vulnerabilities and threats and how to safeguard computer networks from those vulnerabilities and threats. This course will expose the student to network security planning, network security technology, network security organization and the legal and ethical issues associated with network security. This course is designed to prepare the successful student for the CompTIA Security+ certification. Fee is required.

Major Course Concepts

A. Network Security Basics

  • Security definitions, network security principles and objectives
  • Network security architecture, model, and layers
  • Network threats, confidentiality, integrity and availability
  • Accountability, auditability, and non-repudiation
  • Case study of the network security policy

B. Network Security Planning

  • Network risk management and network security policy
  • Continuity of operations and security maintenance
  • Policy, procedures, standards, and guidelines
  • Risk assessment case studies

C. Network Security Technology

  • Cryptography, virtual private networks, firewalls and intrusion detection systems
  • Scanning and analysis tools and access controls

D. Network Security Organization

  • The organization and security
  • Personnel and security
  • The Computer Incident Response Team (CIRT)
  • Security function organization and resources

E. Legal, Privacy, and Ethical Issues

  • US Laws and Network Security
  • Privacy and network security
  • Ethics and Network Security
  • Code of Network Security ethics development

Expected Learning Outcomes
1. Understand computer, network and information security
2. Explain why network security is important
3. Explain network security prevention, detection and response
4. Define and explain network confidentiality, integrity and availability
5. Define and explain the concept of non-repudiation
6. Understand management's role in security development and maintenance
7. Understand the value of education, training and awareness programs
8. Understand security architecture principles and components
9. Define risk management and its role in security policy
10. Understand the relationship between risk, threats, vulnerabilities and countermeasures
11. Identify and describe risk mitigation strategies
12. Define and describe Disaster Recovery Plans
13. Define and describe an Incident Response Plan
14. Define and describe a Business Continuity Plan
15. Describe database security functions
16. Describe and understand a feasibility study
17. Understand the need for constantly evaluating security management status
18. Understand the difference between policies, procedures, standards and guidelines
19. Understand encryption process and define key cryptography terms
20. Understand the difference between asymmetric and symmetric encryption
21. Discuss scanning and analysis tools
22. Describe various types of firewalls
23. Describe various types of Intrusion Detection Systems
24. Describe the operation of Virtual Private Networks
25. Understand authentication importance and good password characteristics
26. Describe various approaches to biometric access control
27. Understand network security element position within organization
28. Understand skills required to staff network security element
29. Describe functional elements associated with network security
30. Understand relationship between employment practices and network security
31. Understand CIRT element position within security function
32. Explain various security professional credentials and their value
33. Identify and explain major laws relating to network security
34. Understand privacy issues and impact on network security function
35. Understand ethics issues and relationship to security function
36. Explain the difference between ethics and laws, and purpose of code of ethics
37. Understand potential organizational liability regarding network security
38. Understand and describe tradeoffs between security, privacy and operations
